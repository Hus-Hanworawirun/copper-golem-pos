# Copper Golem POS (ระบบแคชเชียร์ คลังสินค้า และบัญชีภาษีไทย ม.40(8))

ระบบ Point of Sale (POS) สำหรับร้านค้าปลีกและธุรกิจทั่วไป ทำงานแบบ **Offline-First 100%** ข้อมูลบันทึกลงในเครื่องคอมพิวเตอร์ผ่าน SQLite WAL Mode พร้อมระบบคำนวณต้นทุน-ราคาขายอัจฉริยะแบบหลายแพ็ค ตัดต้นทุนขายจริงแบบ FIFO พิมพ์สติกเกอร์บาร์โค้ด และจัดทำรายงานภาษีตามประกาศกรมสรรพากร (ม.40(8))

---

## การติดตั้งสำหรับผู้ใช้งานทั่วไป (Download & Run)
ไม่ต้องติดตั้ง Node.js หรือโปรแกรมเสริมใดๆ:
1. ไปที่แท็บ **[Releases](https://github.com/Hus-Hanworawirun/copper-golem-pos/releases)** ในหน้า GitHub
2. ดาวน์โหลดไฟล์:
   * **`Copper Golem POS Setup 1.0.0.exe`** (ตัวติดตั้ง พร้อมสร้างไอคอนหน้าจอ Desktop) หรือ
   * **`Copper Golem POS 1.0.0.exe`** (แบบ Portable ดับเบิ้ลคลิกเปิดใช้งานได้ทันที)
3. ข้อมูลสินค้า สต็อก และประวัติการขายจะถูกบันทึกไว้ในคอมพิวเตอร์อย่างถาวรที่โฟลเดอร์:
   `%APPDATA%\CopperGolemPOS\data\pos.db` (ติดตั้งเวอร์ชันใหม่ข้อมูลไม่สูญหาย)

## วิธีรันบนเครื่อง Localhost (Development Mode)
สำหรับนักพัฒนาหรือการทดสอบระบบผ่าน Web Browser:

### 1. ติดตั้ง Dependencies (ทำครั้งแรก)
```bash
npm install
```

### 2. เริ่มต้นฐานข้อมูลตัวอย่าง (หากต้องการข้อมูลทดสอบ)
```bash
npm run db:seed
```

### 3. รัน Backend API Server
```bash
node server/index.js
```
* Backend รันอยู่ที่: `http://localhost:5001`

### 4. รัน Frontend Development Client (เปิด Terminal อีกหน้าต่าง)
```bash
npm run dev
```
* Frontend รันอยู่ที่: `http://localhost:5173`
* เปิดเว็บบราวเซอร์ไปที่ `http://localhost:5173` เพื่อเข้าใช้งานระบบ

## ฟังก์ชันการทำงานหลัก (Core Features)

### 1. ขายหน้าร้าน (Cashier POS)
* **USB Barcode Focus-Free**: รองรับเครื่องยิงบาร์โค้ด USB HID ยิงบาร์โค้ดได้ทันทีจากทุกจุดบนหน้าจอโดยไม่ต้องกดเลือกช่องค้นหา
* **ระบบคิดเงินตรง & คำนวณเงินทอน**: คิดเงินรวดเร็วพร้อมปุ่มรับเงินด่วน (฿100, ฿500, ฿1,000) และคำนวณเงินทอนอัตโนมัติ ไม่บังคับเลือกวิธีชำระ
* **คลังใบเสร็จดิจิทัล (Digital Receipt)**: บันทึกทุกบิลถาวรในระบบ สั่งพิมพ์สลิปซ้ำผ่านเครื่องพิมพ์ความร้อน หรือบันทึกเป็น PDF ย้อนหลังได้

### 2. คลังสินค้า & คิดราคาขายอัจฉริยะ (Smart Pricing Engine)
* **รองรับการซื้อหลายแพ็ค/ยกลัง**: ระบุจำนวนแพ็คที่ซื้อ + จำนวนชิ้นต่อแพ็ค ระบบคูณหายอดชิ้นรวมลงสต็อกให้อัตโนมัติ (`pack_count * pack_qty`) พร้อมแสดงยอดซื้อรวม
* **คำนวณต้นทุนต่อหน่วย & กำไร**: นำราคาต่อแพ็คหารจำนวนชิ้น และบวกกำไร/ชิ้นเพื่อออกราคาขายปลีกหน้าร้านอัตโนมัติ
* **จัดการข้อมูลสินค้าครบวงจร**: แนบรูปภาพสินค้า สุ่มรหัสบาร์โค้ดอัตโนมัติ (Code 128 / EAN-13) และตั้งจุดเตือนสต็อกต่ำ (ROP)

### 3. ระบบพิมพ์สติกเกอร์บาร์โค้ดติดสินค้า
* แสดงตัวอย่างสติกเกอร์ (ชื่อสินค้า + บาร์โค้ด Code 128 + ราคาขายหน้าร้าน)
* สั่งพิมพ์สติกเกอร์บาร์โค้ดเป็นแผ่นตามจำนวนชิ้นสต็อกในระบบ หรือดาวน์โหลดเป็นไฟล์รูปภาพ PNG

### 4. ภาพรวมกำไร-ขาดทุน & บัญชีต้นทุน FIFO (Real-time P&L Analytics)
* **คำนวณผลประกอบการจริง**: ยอดขายรวม (Gross Sales), ต้นทุนขายจริง FIFO (COGS), กำไรขั้นต้น (GP Margin %), ค่าใช้จ่ายดำเนินงาน (OPEX), กำไรสุทธิ (Net Operating Profit)
* **กราฟแท่งวิเคราะห์ช่วงเวลาจริง (Dynamic Time Buckets)**: กราฟพล็อตยอดขายและต้นทุนอัตโนมัติตามช่วงเวลาจริง (รายชั่วโมงวันนี้, 7 วันย้อนหลัง, สัปดาห์ในเดือน, รายเดือน)
* **5 อันดับสินค้าทำกำไรสูงสุด (Profit Champions)**: แสดงสัดส่วนกำไรและยอดขายของสินค้าตัวท็อป
* **งบกำไรขาดทุนย่อ (Condensed P&L Statement)**: สรุปภาพรวมทางการเงิน 5 ขั้นตอน
* **ตรวจสอบการเคลื่อนไหวสต็อกจริง (Stock Logs Audit Trail)**: ตรวจสอบประวัติการรับเข้า การตัดสต็อกขาย และบันทึกบัญชีของสินค้าทุกชิ้น
* **ส่งออกรายงาน .CSV**: รองรับภาษาไทยสมบูรณ์ด้วย UTF-8 BOM เปิดใน Microsoft Excel ได้ทันที

### 5. บัญชีภาษีสรรพากรสำหรับค้าปลีกไทย (ม.40(8))
* **สมุดบัญชีเงินสดรับ-จ่าย (แบบ ป.ส. 10)**: ตามแบบมาตรฐานของกรมสรรพากร (ส่งออก Excel/CSV และสั่งพิมพ์ได้)
* **ระบบเตือนเกณฑ์ VAT 1.8M**: หลอดวัดยอดขายสะสมเทียบกับเพดาน 1,800,000 บาท/ปี เพื่อเตือนการยื่นจด ภ.พ.01
* **เปรียบเทียบภาษีบุคคลธรรมดา (ภ.ง.ด. 90/94)**: คำนวณหักค่าใช้จ่ายตามจริง (FIFO + OPEX) เทียบกับหักเหมา 60% พร้อมแนะนำวิธีที่ประหยัดภาษีที่สุด
* **บันทึกค่าใช้จ่ายดำเนินงาน (OPEX)**: บันทึกค่าเช่า ค่าน้ำ ค่าไฟ ค่าจ้าง ค่าแพ็คเกจ เข้าสมุดบัญชี ป.ส. 10 ได้ทันที

### 6. การจัดการข้อมูลระบบ (Data Management)
* **ใส่ Demo**: โหลดสินค้าตัวอย่างและข้อมูลจำลองมาทดลองเล่นระบบ
* **ล้างระบบ**: ล้างฐานข้อมูลทั้งหมดให้เป็นศูนย์เพื่อเตรียมเปิดร้านจริง

### 7. ระบบอัปเดตอัตโนมัติ (Seamless Auto-Updater)
* ตรวจสอบเวอร์ชันใหม่จาก GitHub Releases อัตโนมัติเมื่อเปิดโปรแกรม
* ดาวน์โหลดอัปเดตแบบเบื้องหลัง และแจ้งเตือนให้รีสตาร์ตเพื่ออัปเดตทันที โดยข้อมูลสินค้าและสต็อกไม่สูญหาย

## คำสั่งทั้งหมดในโปรเจกต์ (Available Scripts)

```bash
# รัน Frontend Development Server
npm run dev

# บิลด์ Frontend สำหรับ Production
npm run build

# รันในโหมด Electron Desktop
npm run electron

# ประกอบไฟล์ติดตั้ง .exe สำหรับ Windows
npm run build:exe

# โหลดข้อมูลตัวอย่าง 5 รายการลงฐานข้อมูล SQLite
npm run db:seed

# ล้างข้อมูลสินค้า ประวัติการขาย และบัญชีทั้งหมดในระบบ
npm run db:clear
```
