# 🐾 POS & Stock Pro (ระบบแคชเชียร์ คลังสินค้า และบัญชีภาษีไทย)

ระบบ Point of Sale (POS) สำหรับร้านค้าปลีกและธุรกิจทั่วไป ทำงานแบบ **Offline-First 100%** ข้อมูลบันทึกลงในเครื่องคอมพิวเตอร์ผ่าน SQLite พร้อมระบบคำนวณต้นทุน-ราคาขายอัจฉริยะ พิมพ์สติกเกอร์บาร์โค้ด และจัดทำรายงานภาษีตามประกาศกรมสรรพากร (ม.40(8))

---

## ✨ ฟีเจอร์เด่น
1. **ขายหน้าร้าน (Cashier & Barcode Scanner)**
   * รองรับเครื่องยิงบาร์โค้ด USB แบบ Focus-Free (ไม่ต้องคลิกช่องค้นหาก่อน)
   * คำนวณเงินทอนอัตโนมัติ / รองรับการสแกน QR Code ประจำร้าน
   * คลังใบเสร็จดิจิทัล (Digital Receipt) บันทึกทุกบิลถาวร สั่งพิมพ์หรือเซฟเป็น PDF ได้ตลอดเวลา
2. **เครื่องคิดเลขต้นทุน & กำไรอัจฉริยะ (Smart Pricing Engine)**
   * ใส่ราคายกแพ็ค (เช่น 1,200) + จำนวนชิ้น (30) -> คำนวณต้นทุนต่อชิ้นอัตโนมัติ (40.00 บาท)
   * ใส่กำไรที่ต้องการ (5.00) -> คำนวณราคาขายปลีกให้อัตโนมัติ (45.00 บาท)
   * แนบรูปภาพสินค้า และระบบสุ่มรหัสบาร์โค้ดอัตโนมัติ
3. **ระบบพิมพ์สติกเกอร์บาร์โค้ดติดสินค้า**
   * แสดงตัวอย่างสติกเกอร์ (ชื่อสินค้า + บาร์โค้ด Code128 + ราคาขาย)
   * ดาวน์โหลดเป็นไฟล์รูป PNG หรือสั่งพิมพ์แผ่นสติกเกอร์ A4 ตามจำนวนชิ้นในสต็อก
4. **บัญชีภาษีสรรพากรสำหรับค้าปลีกไทย (เงินได้ ม.40(8))**
   * **รายงานเงินสดรับ-จ่าย**: ตามแบบมาตรฐานของกรมสรรพากร (ส่งออก Excel/CSV และพิมพ์ได้)
   * **ระบบเตือนเกณฑ์ VAT 1.8M**: แสดงหลอดยอดขายสะสมเทียบกับ 1,800,000 บาท
   * **เปรียบเทียบภาษีบุคคลธรรมดา (ภ.ง.ด. 90/94)**: คำนวณหักตามจริง vs หักเหมา 60%
   * **บันทึกค่าใช้จ่ายร้านค้า**: ค่าเช่า, ค่าน้ำไฟ, ค่าแพ็คเกจ เพื่อนำมาหักภาษีตามจริง

## 🛠️ สำหรับนักพัฒนา (Development & CI/CD)
```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. รันในโหมดพัฒนา
npm run dev

# 3. รันในโหมด Electron Desktop
npm run electron

# 4. ประกอบไฟล์ .exe บนเครื่องตัวเอง
npm run build:exe
```

### การปล่อยอัปเดตเวอร์ชันใหม่ผ่าน GitHub Actions
โปรเจกต์ตั้งค่า GitHub Actions ไว้อัตโนมัติ เมื่อสร้าง Tag เวอร์ชันใหม่ ระบบจะประกอบไฟล์ `.exe` และสร้างหน้า Releases ให้เพื่อนดาวน์โหลดอัตโนมัติ:
```bash
git add .
git commit -m "Release v1.0.0"
git tag v1.0.0
git push origin main --tags
```
